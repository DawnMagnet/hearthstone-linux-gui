# hearthstone-linux-gui v0.3.1 — Hearthstone Linux Launcher

Small release with the features and fixes merged since v0.3.0.

## Highlights

- **Optional login window:** with `hearthstone-linux-gui-login` (`login-helper/`,
  WebKitGTK 6) installed, **Login** opens Blizzard's login page in its own
  window and hands the token back directly; the browser flow stays available
  as a fallback (#36).
- **VSync really off:** with `vsync=0` the launcher also disables VSync at the
  driver level (`vblank_mode=0`, `__GL_SYNC_TO_VBLANK=0`,
  `MESA_VK_WSI_PRESENT_MODE=immediate`) without overriding variables you set
  yourself (#38).
- **HSReplay.net upload:** the collection can be uploaded to HSReplay.net after
  the game launches (#44).
- **Window icon:** the game window now shows the launcher icon (#45).
- **Animated logo** and a separate Unity version status line (#41, #42).
- **Steady download status:** no more flickering text or jumping layout while
  Hearthstone installs (#40).

## Downloads

- **AppImage** — portable x86_64; needs glibc >= 2.34.
- **DEB / RPM / Pacman** — system GTK 4 and libadwaita.
- **Flatpak** — sandboxed x86_64 bundle.
- **Nix** — `nix build github:DawnMagnet/hearthstone-linux-gui/v0.3.1`
