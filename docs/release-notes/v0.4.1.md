# hearthstone-linux-gui v0.4.1 — Hearthstone Linux Launcher

Login tokens stay out of the logs, and old rotated logs are deleted by the
date in the filename.

## Highlights

- **Tokens out of logs:** the Battle.net login callback is no longer written
  to the launcher log or to `auth-callback.log`. That legacy file is removed.
  On the first start after upgrading, older logs are scrubbed once, including
  nested and double-encoded tokens (#84, #86).
- **Private files:** token files are mode `0600`. The login helper and the log
  directory are `0700`, and log files are `0600`. Logs are opened with
  `O_NOFOLLOW` via `libc`, so a symlink is not followed (#84, #86).
- **Two weeks of logs:** a rotated log
  (`hearthstone-linux-gui.log.YYYY-MM-DD`) is removed when its filename date
  is more than 14 days before today (UTC). The newest 14 dated logs are always
  kept, so a clock set far ahead cannot wipe the history. Retention only
  removes files matching that rotated log name (#86).
- **Desktop entries:** `Exec` values escape backslashes, quotes, backticks and
  dollar signs for both layers of the desktop-entry spec (#86).

## 中文摘要

- 登录回调里的令牌不再写入日志，旧的 `auth-callback.log` 会被删除。升级后第一次
  启动会把历史日志里的令牌打码一次，包括嵌套和双重百分号编码（#84、#86）。
- 令牌文件为 `0600`，登录助手和日志目录为 `0700`，日志文件为 `0600`。日志以
  `O_NOFOLLOW` 打开，不跟随符号链接（#84、#86）。
- 按文件名里的日期清理滚动日志，并始终保留最新的 14 个，时钟被拨快也不会清空
  历史。只会删除符合滚动日志文件名的文件（#86）。
- 桌面项 `Exec` 按规范转义反斜杠、引号、反引号和美元符号（#86）。

## Downloads

- **AppImage** — portable x86_64, built on Enterprise Linux 8; needs glibc
  >= 2.28 (Debian 11, Ubuntu 20.04, and newer).
- **DEB / RPM / Pacman** — system GTK 4.6 and libadwaita 1.1 (Ubuntu 22.04,
  Debian 12, Enterprise Linux 9, Fedora 36 and newer).
- **Flatpak** — sandboxed x86_64 bundle.
- **Nix** — `nix build github:DawnMagnet/hearthstone-linux-gui/v0.4.1`
