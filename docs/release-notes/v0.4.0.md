# hearthstone-linux-gui v0.4.0 — Hearthstone Linux Launcher

The launcher now runs on every distribution that ships GTK 4. Native packages
target GTK 4.6 and libadwaita 1.1, and the AppImage is built for glibc 2.28.

## Highlights

- **Wider support:** native deb, rpm and pacman packages target GTK 4.6 and
  libadwaita 1.1 (Ubuntu 22.04, Debian 12, Enterprise Linux 9, Fedora 36 and
  newer). They still compile against the GTK 4.4 API so Enterprise Linux 9's
  Pango 1.48 can link them (#57, #64).
- **AppImage on older glibc:** built on AlmaLinux 8 (glibc 2.28) with GTK 4.12
  and libadwaita 1.4 from source. It runs on Debian 11, Ubuntu 20.04 and newer.
  Native packages stay on the AlmaLinux 9 build (#63).
- **Faster installs:** BLTE decoding, the content MD5 check and the file write
  run off the async runtime. Decompression uses zlib-rs, about 1.5× faster,
  and installs are about 1.1–1.8× faster (#82).
- **Dependencies within that baseline:** aes 0.9 and cbc 0.2, pbkdf2 0.13, and
  rustls updates. `cargo audit` is clean on both lock files. relm4 stays at
  0.10.1 and the GTK crates stay on the 4.6 / 1.1 ceiling (#76, #78, #81).
- **Clearer settings and uninstall:** uninstall asks before deleting game
  files (#61). Region and game-language dropdowns show readable names; the
  game still receives the original codes (#62).
- **Language switches in place:** headers, menus, dialogs and status text
  update in the open window. An install, login or running game is not
  interrupted (#56).

## Maintenance

- CI runs `cargo audit` on both lock files (#77). Dependabot opens one grouped
  version-update pull request per ecosystem each month (#75). GitHub Actions
  are updated to checkout 7, the artifact actions 7 and 8, and the Docker
  build actions (#65, #66, #69, #70, #72).
- Pull requests run rustfmt, clippy `-D warnings` and the workspace tests, and
  check the GTK 4.6 / libadwaita 1.1 feature ceiling (#59).
- The AppImage keeps the game's own `LD_LIBRARY_PATH` when there is no
  GameMode or MangoHud wrapper (#58).

## Downloads

- **AppImage** — portable x86_64, built on Enterprise Linux 8; needs glibc
  >= 2.28 (Debian 11, Ubuntu 20.04, and newer).
- **DEB / RPM / Pacman** — system GTK 4.6 and libadwaita 1.1 (Ubuntu 22.04,
  Debian 12, Enterprise Linux 9, Fedora 36 and newer).
- **Flatpak** — sandboxed x86_64 bundle.
- **Nix** — `nix build github:DawnMagnet/hearthstone-linux-gui/v0.4.0`
