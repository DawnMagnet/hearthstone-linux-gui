# hearthstone-linux-gui v0.3.0 — Hearthstone Linux Launcher

Feature release. The launcher is now translatable, has a compact single-button
layout, and gains the settings and diagnostics that were most requested in
issues: GameMode / MangoHud, a game settings editor, and a one-click system
information report for bug reports.

## Highlights

- **System information for bug reports:** the gear menu shows launcher
  version, install kind, distribution, kernel, session type (Wayland / X11),
  graphics driver, OpenGL renderer, Mesa version, GameMode, MangoHud, GTK and
  libadwaita versions, with a button that copies everything. Please paste it
  into new issues; it answers most "which GPU / compositor?" questions up
  front (#37).
- **Translatable launcher:** English, German and Simplified Chinese are
  included, selectable from the gear menu with a flag per language. By default
  the launcher follows the system locale, and region and game language are
  preselected from it on first start (#29).
- **GameMode and MangoHud switches:** the game starts as
  `gamemoderun mangohud <game>`. A switch is disabled with an explanation when
  the tool is not installed or, in the Flatpak, not reachable from the sandbox
  (#30).
- **Game settings editor:** frame-rate limit, VSync and graphics quality, plus
  plain editors for `options.txt` and extra `client.config` entries. Extra
  `client.config` entries now survive Install / Update (#31).
- **Compact layout, one Login/Play button:** the window opens at its smallest
  size and the content is centred. The button reads **Login** while logged out
  and **Play** once logged in; Log Out and Switch Account are in its menu
  (#33). While a login is pending, a hint explains that Blizzard's login page
  is built for the game's own browser and can be hard to read in a regular one
  (#34).
- **Optional update check, off by default:** when enabled, a newer launcher
  release shows an upgrade button that opens the release page. Nothing is
  downloaded or installed by the launcher (#35).
- **New name and icon:** "Hearthstone Linux Launcher — Unofficial community
  launcher", with an original logo. Binary name, package name and application
  ID are unchanged (#32).

## Upgrade notes

- No action needed. Existing installs, logins and settings are kept.
- Users on 0.2.0 or earlier should upgrade: the `CoreFoundation` import fix
  (the `DllNotFoundException ... CoreFoundation` error in `Player.log`) shipped
  in 0.2.1.
- Packagers whose distribution upgrades the launcher itself can build with
  `HEARTHSTONE_LINUX_NO_UPDATE_CHECK=1` to remove the update check.

## Downloads

- **AppImage** — portable x86_64; needs glibc >= 2.34 (RHEL/Alma/Rocky 9,
  Ubuntu 22.04, Debian 12, Fedora 35+, and newer).
- **DEB / RPM / Pacman** — system GTK 4 (>= 4.0) and libadwaita (>= 1.0); same
  glibc floor.
- **Flatpak** — sandboxed x86_64 bundle, attached a few minutes after the other
  files.
- **Nix** — `nix build github:DawnMagnet/hearthstone-linux-gui/v0.3.0`

## Verification

Download `SHA256SUMS.txt` from the GitHub release and run:

```sh
sha256sum -c SHA256SUMS.txt
```

## Notes

Rendering problems on some AMD/Wayland setups (flicker or black screen, see
#13) are still under investigation. If you hit one, please attach the new
system information report.
