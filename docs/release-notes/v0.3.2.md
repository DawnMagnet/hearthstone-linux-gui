# hearthstone-linux-gui v0.3.2 — Hearthstone Linux Launcher

Small release with the French translation and the Nix packaging fixes merged
since v0.3.1.

## Highlights

- **French translation:** the launcher can run in French (`locales/fr.toml`).
  A `fr_*` system locale selects it, and it is also in the gear menu (#47).
- **NixOS media plugins:** the Nix package ships the GStreamer plugins the
  animated logo needs, so startup no longer fails with
  `playbin3 element not found`. `GST_PLUGIN_SYSTEM_PATH_1_0` is set by the
  wrapper (#53).
- **Crane packaging:** Nix builds use Crane. Dependencies stay cached across
  source changes, and the runtime closure dropped from about 4.1 GB to about
  2.2 GB (#54).
- **No cargoHash step:** releases no longer recompute or commit a vendor hash.
  Crane reads `Cargo.lock` directly (#50, #51, #55).

## Maintenance

- HSReplay memory reader uses `as_chunks` (#48).
- Clean-room commerce SDK notes in `docs/commerce-spec.md` (#49).

## Downloads

- **AppImage** — portable x86_64; needs glibc >= 2.34.
- **DEB / RPM / Pacman** — system GTK 4 and libadwaita.
- **Flatpak** — sandboxed x86_64 bundle.
- **Nix** — `nix build github:DawnMagnet/hearthstone-linux-gui/v0.3.2`
